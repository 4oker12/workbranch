SIMNET Workbench v1.7.17 — контрольный прогон

A. GUIDE / ЗАГРУЗКА DOM
[ ] Быстро нажать «Получить подсказку» сразу после перехода на страницу.
    Ожидание: ничего не мигает в левом/случайном месте; затемнения страницы нет.
    Комментарий:

[ ] Несколько раз быстро нажать «Получить подсказку» во время загрузки/перерисовки Billing.
    Ожидание: действует только последний актуальный запрос; старые подсказки не всплывают позже.
    Комментарий:

[ ] Обычная подсказка на уже загрузившейся странице.
    Ожидание: только тонкая рамка цели + карточка; без полного затемнения.
    Комментарий:

B. НЕПРАВИЛЬНАЯ ВКЛАДКА ОПРОСА
[ ] На известном EPON-кейсе вручную открыть GPON (a311) и нажать «Запрос OLT».
    Ожидание: ошибки/CLI-блоки НЕ завершают диагностику и НЕ дают POLL COMPLETE.
    Комментарий:

[ ] После этого открыть правильный EPON (a310) и опросить.
    Ожидание: реальный ответ ONU завершает Guide.
    Комментарий:

[ ] Проверить ONU offline/LOS на ПРАВИЛЬНОМ адаптере.
    Ожидание: если оборудование реально вернуло ответ по ONU — Guide завершается; offline/LOS остаётся фактом интерпретации.
    Комментарий:

C. MAC HISTORY / ОБОРУДОВАНИЕ
[ ] Поиск MAC привёл на Arista/Cisco/Juniper/Port-Channel.
    Ожидание: Workbench НЕ предлагает записать это устройство как OLT; ведёт на проверку интерфейса/топологии.
    Комментарий:

[ ] Поиск MAC действительно привёл на PON OLT.
    Ожидание: OLT-кандидат допускается только при признаках PON/OLT, затем обычная сверка/заполнение Billing.
    Комментарий:

D. РЕГРЕССИЯ
[ ] Правильный EPON poll ONLINE завершается.
[ ] Правильный EPON poll OFFLINE/LOS завершается при реальном ответе ONU.
[ ] Huawei poll с реальным ответом завершается.
[ ] Просто открытая вкладка опроса без ответа не завершается.
[ ] CLI error / invalid input / no such ONU не завершают Guide.
